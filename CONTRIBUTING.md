# Contributing

Thank you for helping improve MenfessBot.

## Workflow
1. Find or open an issue describing a real improvement.
2. Create a focused branch from main.
3. Make a small, reviewable change.
4. Run: PYTHONPATH=src python -m unittest discover -s tests -v
5. Open a pull request explaining the change and test results.

## Pull request checklist
- [ ] The change solves a real issue.
- [ ] Tests pass.
- [ ] No secrets or personal data are included.
- [ ] Documentation is updated where needed.
- [ ] Privacy and moderator authorization are considered.

Contributors must make their own genuine changes. Reviews should address actual code or documentation. Do not claim co-authorship unless the named person contributed to that commit.
